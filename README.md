# eSportsMirror: versioni

Installer e app per Android di eSportsMirror, il programma della regia eSports FITP che porta lo schermo dei telefoni sui monitor.

Qui ci sono solo le versioni compilate: il programma installato controlla questo repository all'avvio e, quando c'è una versione nuova, propone «Aggiorna ora». Gli aggiornamenti sono firmati e il programma accetta solo quelli firmati con la chiave di chi lo pubblica.

- **Prima installazione su Windows:** dall'ultima release, `eSportsMirror-<versione>-setup-win64.exe`. Dove non si può installare nulla c'è lo zip portatile.
- **App per Android:** `eSportsMirror-<versione>.apk`.
- Accanto a ogni file c'è la sua impronta SHA-256.

Componenti di terzi inclusi: scrcpy (Apache 2.0), adb, FFmpeg (LGPL), SDL3, Node.js; elenco completo in `THIRD-PARTY.txt` dentro l'installazione. NDI® è un marchio registrato di Vizrt NDI AB.
